▲战舰单数FLEET

屏幕上的数字从哪来

一条线索数的是船身格数，不是船的数量。规则口径写死在 js/core/rules.js：船是直线段，任何两格相邻（含斜角）的船不能共存 —— 这一条决定了推理能推多远，改了它，仓库里所有 fixture 与枚举表全部作废。

唯一解 那个 1 不是声明，是两次独立计数的结果：js/core/solve.js 先纯推理（线索饱和、空格裁剪、斜角禁入、超长段裁水），推不动就整条船为单位假设并回溯，计数器封顶在 2；js/core/enumerate.js 走完全暴力的第二条腿——先枚举棋盘上所有合法摆法（只看舰长与不相邻，一个线索都不看），再用线索过滤枚举表数解。两条路线对每个出货题面必须给出同一个解数与同一个船格集合，见 node test/enumerate.test.mjs 与 node test/lots.test.mjs。

假设层数 与 推理枯竭 是求解器解这一题时的实测栈深与枯竭次数：0 表示线索本身就能推到底。分带（纯推理 / +1 假设 / +2 假设）按这个数切，不按感觉切，见 node tools/bake.mjs 打印的表。
